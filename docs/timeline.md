# 功能 C：一首歌的「性格变化」（滑动窗口时间轴）

## 目的

流派标签通常被当成整首歌的静态属性，但真实音乐是变化的：前奏安静、主歌平稳、
副歌爆发。本功能把一首歌切成多个 **5 秒窗口**（步长 2.5 秒），对每个窗口分别做
流派分类，画出「模型在整首歌里听到的东西」随时间的变化。

这不是预测未来尚未播放的音频，也不是音乐生成，而是**对不同时间片段分类**，
与主实验使用完全相同的模型与预处理。

## 方法

- 输入：任意音频，librosa 重采样到 22,050 Hz 单声道。
- 窗口：5 秒，步长 2.5 秒；最后一个窗口对齐到音频结尾，避免出现不足 0.1 秒的重复尾窗。
- 模型：默认 CNN（seed 42），也可选 SVM / MLP / CRNN / Transformer。
- 输出：每个窗口的 Top-1 与 10 类概率；热力图 + 逐窗表格。

PY=/home/weizai0v0/.apps/anaconda3/envs/DataAnalysis/bin/python

## 测试集扫描：模型真的会「改主意」吗？

对 147 首测试曲目逐首切片（11 个窗口），统计 Top-1 发生变化的位置：

- **88 / 147 首**（约 60%）至少出现 1 次窗口级判断变化；
- 最不稳定的是 `rock.00072`（9 次变化，判过 rock / disco / blues / country），
  该曲目整首被 clip-level 判为 rock，但局部段落听起来更像 disco/country；
- 最稳定的是 classical 类曲目，11 个窗口全部一致。

完整扫描结果：`results/timeline_scan.csv`。

## 两个对比例子

**会变卦的摇滚：`rock.00072`**

![rock.00072 时间轴](../results/figures/timeline_rock.00072.png)

- 0–2.5 s：rock（78%）
- 2.5–10 s：disco / blues（置信度只有 38–40%，模型自己也不确定）
- 12.5–22.5 s：disco 与 rock 交替
- 22.5–27.5 s：country
- 最后 5 s：rock

**从头稳到尾的古典：`classical.00001`**

11 个窗口全部判为 classical，概率 94%+。

## 现场怎么讲

1. 先放整首或长片段，让观众猜流派；
2. 展示整段预测（clip-level）与时间轴（window-level）的差异；
3. 挑出「模型改主意」的段落单独播放，问观众：这一段像不像另一个流派？
4. 落到结论：**流派不是整首歌的静态标签**，模型的犹疑恰好反映了音乐本身的变化；
   同时提醒，窗口级准确率低于整段准确率，短片段信息更少。

## 局限

- 窗口越短，模型越容易受局部配器影响，置信度普遍下降。
- GTZAN 每首仅 30 秒，窗口只有 11 个，时间分辨率有限。
- 该功能展示的是「不同片段的分类」，不能解释为「预测下一段会是什么」。
