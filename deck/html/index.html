模型不是白纸

模型生来就信的假设数据少时数据多时
SVM / MLP自己没有先验，但输入的人工特征里全是稳，天花板低天花板低
CNN局部性 + 平移等变强强
CRNN局部性 + 循环层的记忆稍弱更强
轻量 Transformer只有位置编码，几乎没有结构先验严重过拟合待观察
AST架构同上，预训练把先验灌进权重最强最强

先验越少，样本效率越低；先验越少，天花板越高。这是一枚硬币的两面。

为什么只有 3 秒

续写长度耗时（RTX 4060）情况
3 秒5.6 s8/8 曲目稳定，主结果口径
6 秒16.3 s可生成
8 秒18.3 s可生成
12 秒35.4 s可生成
16 / 20 秒—崩：位置索引越界

崩的原因不在长度：pad/bos 的 id 是 2048，而词表只到 2047。

3 秒是「八首都能稳定跑完」的口径，不是能力上限。

来源：demo/README.md §3.5

指标不等于好听

指标：Log-Mel RMSE——离原曲多近

没做：规模化主观听感评分

所以我们只说「客观距离变近了」，不说「变好听了」。

结案

判别式：最大的单点收益是预训练，不是架构
模型排序会随数据规模翻转：985 首 CNN 赢，7,994 首 CRNN 反超
泄漏能让结论虚高十个点：0.470 → 0.568
生成式：能预测，学得很少，修好对齐后有可测改善，三个旋钮无效

五个负结果都留在报告里：正则化无效 · 轻量 TF 小数据崩 · 噪声下 CNN 垫底 · LoRA 初版失效 · 三旋钮无效

我们没把「跑通」当成「做好」。
